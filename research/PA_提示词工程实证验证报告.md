# PA_Agent 提示词工程实证验证报告（v2，已更正）

> **版本说明**：第一版报告有多处定义错误，结论已被本版取代。第一版中被撤回或修正的结论见文末「撤回清单」。
> 数据：`D:\MT5_K线数据` 的 XAUUSD、US100.cash、US500.cash，M5 / M15 / H1 / H4 / D1。
> 脚本：`research/pa_validation/*_v2*.py`，复现方式见该目录 README。
> 特征定义复用项目源码（EMA20、ATR14、棒型分类、突破分层）。

## 方法上的两条硬规则

第一版的主要问题是缺少基线，v2 加了两条规则。

1. **每个数字都要和"打乱 bar 顺序的替代序列（NULL）"对比。**
   很多说法本质是"先到目标还是先到止损"的竞赛，答案主要由距离几何决定。同一个检测器在 NULL 上也给出同样的数字，就说明这个数字不是市场结构的证据。有信息量的是 REAL 和 NULL 的差。
2. **模拟入场必须真的成交，定义要做敏感性对比。**
   同一个概念用不同定义，数字可以从 30% 变到 80%。所以每项都报告多种口径。

| 微通道第一次突破失败 >80% | 趋势恢复 52–67%，不高于 NULL | **不能复现，建议删数字** |

## 逐项说明

### 1. 区间突破（Test 1 v2）

**第一版的定义问题**：区间只靠"20 棒包络 + EMA 走平 + 重叠"，没有要求上下沿被测试过，很多"区间"其实是普通回调。影线试探的"失败"判据太松，事件还被重复计数。

**v2 的区间定义**（窗口 N=20 和 40）：

- L0（旧定义）：宽度 2–12 ATR，EMA 走平，平均重叠 ≥0.35。
- L1：L0 加上沿、下沿各被测试 ≥2 次（距边界 15% 区间高度以内，两次间隔 ≥3 棒）。
- L2：L1 加 EMA 穿越 ≥3 次，且净位移 <0.4 倍区间高度。

**结果（N=40，收盘突破，被收回 = 项目口径 "failed"）**：

| 区间级别 | REAL 5 棒内被收回 | NULL |
|---|---|---|
| L0 | 54.7% | 45.0% |
| L1 | 53.2% | 43.3% |
| L2 | 53.8% | 37.2% |

- 区间越"真"，收盘突破被收回的比例相对 NULL 越高（L2 高出约 17 个百分点）。这是有信息量的发现。
- 竞赛口径下（先到 `边界+1.0×区间高度` 还是先回落 `边界−0.25×高度`），收盘突破的成功率只有 31–39%，但这个数字受几何影响，不能直接当作"失败率"。
- 影线试探用同样的竞赛口径，到 +0.5 倍高度前先回落的比例约 75–81%，NULL 也一样。

**对提示词的含义**：提示词原文已经分层（影线/未站稳 70–80%，仅收盘越界失败率更低，存活后约 60% 到 MM），分层写法与数据相容。第一版我把 70–80% 拿去比"全部尝试"，是误读。**这一项不需要改**，最多补一句"严格区间里收盘突破 5 棒内被收回约 53%，高于随机约 40%"。

### 2. 微通道第一次突破（Test 3 v2）

**第一版的定义问题**：第二版把"突破"定义为任何一根更低的低点，"失败"定义为先碰哪一边。两个相邻价位的先后顺序近似抛硬币，所以 46% 没有意义。

**v2**：微通道 = 连续 ≥5（或 ≥7）根低点不下移的上行段，净推进 ≥2 ATR。第一根出现更低低点的棒视为"第一次破位"。比较"先创出新高（趋势恢复）"和"破位继续延伸"，用三组几何，并设两个对照：普通强势段、打乱序列。

| 几何（恢复位 / 延伸位） | 微通道 REAL | 微通道 NULL | 普通强势段 REAL |
|---|---|---|---|
| 通道高点 / 破位低点−0.5 ATR | 57.9% | 62.2% | 49.2% |
| 通道高点 / 破位低点−1.0 ATR | 66.8% | 69.9% | 58.5% |
| 通道高点+0.5 ATR / 破位低点−1.0 ATR | 52.2% | 54.7% | 47.1% |

- 趋势恢复的比例是 52–67%，取决于几何，没有一种定义接近 80%。
- 微通道比普通强势段高 5–9 个百分点，但这部分受几何影响（微通道的最后一根棒贴着高点），且都不高于 NULL。

**结论**：">80%"无法复现，建议从提示词删掉这个数字，保留"第一次破位偏向恢复、不作强门控"的定性表述。这一项结论和第一版一致，但依据更可靠。

### 3. H1/H2 计数（Test 4 v2）

**第一版的定义问题**：把"H1 之后的第二次上破"当成 H2，没有要求中间出现新的下探腿；入场晚一棒；没有对照。

**v2 的规范定义**：

- 摆动高点用分形确认（左右各 2 棒），回撤状态从确认时开始。
- 回撤中某棒高点突破前一棒高点即为触发，信号棒是前一棒。入场 = 信号棒高点 +1 tick（必须成交），止损 = 信号棒低点 −1 tick。
- 计数规则：触发后"解除武装"，只有后续出现跌破该信号棒低点（即这笔 H 会被止损）时才重新武装。第 n 次触发记为 Hn。
- 背景要求 EMA20 上行，按 10 棒斜率分三档。
- 成交棒按保守约定处理（该棒低点触及止损算亏），之后先判止损再判目标，30 棒未了结按收盘价盯市。

**结果（目标 1R，期望值 E[R]，三品种汇总）**：

| 分组 | H1 | H2 | H3+ | 任意上破（对照） |
|---|---|---|---|---|
| 全部 | −0.258 | −0.323 | −0.323 | −0.136 |
| 弱趋势 | −0.228 | −0.241 | −0.272 | −0.140 |
| 中趋势 | −0.257 | −0.337 | −0.346 | −0.135 |
| 强趋势 | −0.270 | −0.352 | −0.362 | −0.136 |

- H2 的期望值不比 H1 高。全样本下 H2 低约 0.065R，差异显著（H1 为 ±0.011，H2 为 ±0.016）；弱趋势下两者无差别。
- 所有 H 触发都不如"任意上破"对照。
- 绝对值为负，主要来自保守成交约定和紧止损，只看组间相对差才有意义。2R 目标下结论相同。

**结论**："H2/L2 优于 H1/L1"没有数据支持。Brooks 的这个说法更像情境判断（结构更干净、止损更小），不是可测的概率事实。建议提示词改成情境表述，不要当概率锚点。

### 4. 趋势棒与连串（Test 5 v2）

**第一版的错误**：我把"后 2 棒任一收盘更高"的 60–61% 当成"高于 50% 的边际"。随机游走下这个统计量的基线是 62.5%，所以 60–61% 并不是边际。

**v2**（按项目定义的 trend_bull / trend_bear，约 90 万个样本，ATR 单位）：

| 统计量 | 趋势棒（顺向） | 全部 bar | 非趋势棒 |
|---|---|---|---|
| 下一棒收盘更远 | 48.2% | 49.5% | 49.5% |
| 后 2 棒任一更远 | 61.0% | 62.2% | 62.2% |
| 先 +1 ATR 还是先 −1 ATR | 49.1% | 49.2% | 49.1% |
| 3 / 5 / 10 棒前向收益 | −0.010 / −0.004 / +0.003 | 0 | 0 |

- 趋势棒后续没有方向优势。强棒和弱棒没有区别（后 2 棒 60.3% vs 61.2%）。
- 连串长度 k=1..4 时下一棒同向 48.5%→46.5%，每一档前向收益都在噪声内。k≥5、k≥6 的前向收益是正的，但置信区间很宽（k=6+ 的 10 棒收益 +0.29±0.28 ATR），不显著。

**结论**：第一版"4 根以上趋势棒后 <50%，应按高潮处理"的数据依据不成立，已撤回。数据没有支持也没有反驳"长串后衰竭"。同时，"趋势棒本身能提高后续概率"也没有数据支持，因此提示词中"趋势棒后多有跟随"不应写成概率优势，只能作为事后确认条件。

### 5. 20GB 首次触及 EMA（Test 7 v2）

**第一版的错误**：模拟里没有要求价格真的触到入场价，没成交就先下跌的情形也被记成"反转"。28% vs 69% 是 bug，作废。

**v2**：缺口棒 = 低点高于 EMA20。事件 = 至少 3 根缺口棒之后第一根触及 EMA 的棒。按缺口长度 g 分桶，短桶（3–9）当对照，20 以上为 20GB。入场为触及棒高点 +1 tick 的止损单，3 根内必须成交。

| g | 有成交 scalp 1R 的 E[R]（REAL / NULL） | 10 棒后收盘在 EMA 上方（REAL / NULL） |
|---|---|---|
| 3–5 | −0.115 / −0.211 | 50.8% / 50.7% |
| 10–14 | −0.086 / −0.204 | 49.5% / 50.1% |
| 20–29 | −0.127 / −0.254 | 52.5% / 50.0% |
| 30+ | −0.092 / −0.241 | 56.0% / 49.5% |

- 成交率约 40%，各桶一致。
- g≥20 的 scalp 期望值不优于 g=3–5，所以 20GB 对"顺势刮头皮"没有额外优势。
- 10 棒后的位置随 g 增大有温和的趋势延续倾向（g≥30 比 NULL 高约 6 个百分点），但 10 棒前向收益（+0.13±0.12 ATR）不显著。
- "先创新高还是先破 EMA 之下 0.5/1.0 ATR"的竞赛，REAL 和 NULL 没有差别。

**结论**：首次触及 EMA 不是反转信号（没有反转倾向），这点提示词成立。但"顺势机会"缺乏可交易优势的证据。建议降级措辞为"不视为反转；顺势优势不显著，不作为独立入场理由"。

### 6. 回撤深度分档（Test 6 v2）

第一版把"<30%→92%、30–50%→84%、50–78.6%→73%、>78.6%→53%"称为最扎实的发现。v2 对比打乱序列：

| 分档 | REAL | NULL |
|---|---|---|
| <30% | 91.8% | 93.5% |
| 30–50% | 84.2% | 85.4% |
| 50–78.6% | 72.7% | 73.4% |
| >78.6% | 53.4% | 57.6% |

这个阶梯主要由几何产生：目标距离随回撤加深而变远。真实市场在深回撤时比随机序列还略低。**分档作为分类规则仍然合理，但不应把这组数字写进提示词当成趋势性的实证概率。第一版的"最扎实"判断撤回。**

### 7. 尖峰余波（Test 2 v2）

| | REAL | NULL |
|---|---|---|
| 延续 | 64.0% | 66.1% |
| 区间 | 17.7% | 13.0% |
| 粘性反转 | 18.3% | 20.9% |

提示词的"15–20%"作为基础比率与数据一致，但随机序列也给出同样大小的数字，所以它不是尖峰特有的信息。分周期看：H1 反转 14.2%（NULL 23.3%），D1 反转 25.0%（NULL 15.7%）。第一版说"强力证实"过头了，改为"基础比率相符"。

### 8. 程序 `hl_count`（新发现，可操作）

用项目真实的 `compute_simple_market_features` 在 900 个真实 100 根窗口上统计：

- 多头候选：h3 占 67.7%，h2 占 8.9%，h1 占 9.1%，none 占 14.3%。
- 空头候选：l3 占 65.1%。
- 计数中位数 5，最大 29。

原因是 `_compute_hl_count` 对窗口内每根"高点高于前一棒"的 bar 都 +1，只在大阳线/大阴线反向收盘时清零，不是 Brooks 按"单次回撤"计数的 H1/H2。所以提示词里的 `h1/h2/h3` 判断依据和程序给的计数基本脱节，模型拿到的几乎总是 h3。这个问题比任何概率数字都更影响实际行为。

## 局限

- 所有机械回测用固定 R 或固定 ATR 目标，不代表带结构止损和交易者方程的 Agent 实盘表现。
- 区间、微通道的几何检测是简化规则，与 LLM 的语义识别不完全等价。
- 事件之间有重叠，置信区间偏乐观；NULL 是 i.i.d. 打乱，没有保留波动聚集，真实市场的差异可能部分来自这一点。
- 没有检验"这些提示词对 LLM 输出质量的影响"。这里验证的是提示词里的市场说法是否成立，不是 Agent 的交易绩效。
