# 缺口检验预注册

> 这份文件在**运行任何缺口结果统计之前**写定，运行后不得修改定义、分层、窗口或阈值。
> 如果发现代码 bug，修复后必须在结果文档里注明改了什么，并重新跑全部假设。
> 概念定义见 `GAP_DEFINITIONS.md`，检测器已通过 18 项测试和 9 种植入错误的变异测试（`test_gap_defs.py`）。

## 已确认的定义选择（你确认的 5 点）

1. FVG 几何：看涨 `l[t] > h[t-2]`，区域为 `[h[t-2], l[t]]`；看跌是镜像。
2. **主检验用 G3S**（中间棒是顺向趋势棒，且全幅 ≥ 1.0 × ATR14[t-2]），只取每一段连续缺口里的**首个**事件。G3T 与 G3 只做敏感性，不参与判定。
3. 不设最小尺寸下限，改为按尺寸分层比较。
4. 排除跨时段缺口（相邻两根的时间间隔 > 1.5 倍周期）。
5. 本轮不做测量移动目标。

## 通用规则

**数据**：XAUUSD、US100.cash、US500.cash。主周期 **M15**；稳健性 M5、H1。

**前后半段**：每条序列按 bar 序号对半切。前半段为样本内（IS），后半段为样本外（OOS）。事件按其第三根棒的序号 `t` 归入哪一半。结果窗口可能跨过分界线，属于轻微泄漏，可忽略。

**单元与合并**：独立单元是黄金与指数（US100 与 US500 的 z 取平均）。总 z = (z黄金 + z指数) / √2。

**判定规则**（对每个假设，在主周期上）：

| 条件 | 结论 |
|---|---|
| IS 的 \|总 z\| ≥ 3，且 OOS 同号并且 \|总 z\| ≥ 2 | **成立** |
| IS 的 \|总 z\| ≥ 3，但 OOS 不同号或 \|总 z\| < 2 | **过拟合 / 不稳** |
| IS 的 \|总 z\| < 3 | **未发现**（同时报告标准误与最小可检测效应） |

**零效应校准**：正式运行之前先做 placebo：把“真实数据”和“对照”都换成互相独立的随机零模型，各跑多次，检查 z 的标准差与假阳性率。阈值不因校准结果而改动；若 z 明显膨胀，在结果里如实降低对“成立”的信心。

**多重检验**：本轮共 3 个假设（H6a、H6b、H7），阈值沿用上一轮的 3 / 2。

## 假设

### H6a　磁铁：缺口被回头测试的概率高于随机

Brooks：“缺口是磁铁”，并且“缺口常在之后很多根内被测试”。

- 样本：G3S 首个事件，窗口 N = 20 根，要求窗口完整（`t + 20 ≤ n − 1`）。
- 指标：**测试**——窗口内是否有某根进入区域上沿（看涨 `l[k] ≤ z_hi`；看跌 `h[k] ≥ z_lo`），`k ∈ [t+1, t+20]`。
- 对照：VOL 零模型（随机镜像每根 bar，保留 bar 大小顺序），在其上用**同一个检测器、同一个口径**。
- **分层比较**（避免几何差异造成假象）：每个事件按两个变量分入 15 个层：
  - 缺口大小 `size_atr`：`<0.1`、`0.1–0.25`、`0.25–0.5`、`0.5–1.0`、`≥1.0`（单位 ATR）。
  - 事件确认时收盘价到近端边缘的距离 `dist_atr`（看涨 `(c[t] − z_hi)/ATR14[t-2]`，看跌 `(z_lo − c[t])/ATR14[t-2]`，恒 ≥ 0）：`<0.5`、`0.5–1.5`、`≥1.5`。
- 统计量：每层的 `p_测试(真实) − p_测试(VOL)`，按真实事件数加权平均。某层真实或 VOL 样本不足 30 则该层丢弃，权重重新归一。标准误 `sqrt(Σ w² (se_真实² + se_VOL²))`。
- 期望方向：正。双侧检验。

### H6b　“测试但不填满”：被测试之后，填满的概率低于随机

Brooks：这类缺口“常被测试，但不被填满”，并且是买方强势的证据。

- 样本：H6a 中已被测试的事件。
- 指标：**填满**——窗口内是否有某根到达区域远端（看涨 `l[k] ≤ z_lo`；看跌 `h[k] ≥ z_hi`）。
- 对照与分层：同 H6a。
- 统计量：每层的 `P(填满 | 已测试)`，真实减 VOL，按真实“已测试”事件数加权平均。
- 期望方向：负。双侧检验。

### H7　强势信号：缺口之后的方向表现优于没有缺口的强趋势棒

Brooks：微型缺口是强势信号。

- **缺口组**：G3S 首个事件。
- **对照组**：中间棒同样是“强趋势棒”（与 G3S 完全相同的条件），但第三根棒**没有**形成缺口（`l[t] < h[t-2]`，看跌镜像；等于的情形两组都不要）。同样只取各自连续序列里的首个。
- 指标：方向调整后的前向收益 `R = (c[t+10] − c[t]) / ATR14[t-2]`（看跌取负），N = 10 根。
- 分层：中间棒全幅/ATR14[t-2]：`1.0–1.5`、`1.5–2.5`、`≥2.5`，三层。
- 统计量：每层的 `mean R(缺口组) − mean R(对照组)`，按缺口组事件数加权平均；标准误来自两组在该层的样本方差。
- 对照是同一份真实数据里的另一组事件，不用 VOL。
- 期望方向：正。双侧检验。

## 敏感性（不参与判定）

- G3T、G3 两个等级。
- H6 的窗口 N = 60；H7 的 N = 5、20。
- 周期 M5、H1：方向是否与 M15 一致。

## 不属于本轮的

- 任何在看到结果后才想到的条件（改尺寸分层的边界、改距离分层、改 N、加入新的筛选）不得进入判定；可以另开“探索性”小节，但必须标明样本内已看过。
- 测量移动目标、开盘跳空、岛形反转、突破缺口 / 衰竭缺口分类（原因见 `GAP_DEFINITIONS.md` 第 5 节）。

## 已知局限

- 事件之间存在重叠，z 偏乐观；通过 placebo 校准评估膨胀程度，并通过“只取首个事件”来降低重叠。
- 三个品种的数据已在本研究的其他环节被多次使用，预注册只约束这一轮。
- “分层后加权平均”只控制了尺寸与距离这两个几何变量，不能排除其他未控制的差异。
