# 缺口概念的精确定义（检测器依据）

> 本文件先于任何结果统计写成。所有定义来自 Brooks 原文（`Trading Price Action` 三本书与其术语表）；FVG 的定义**不在资料里**，来自我对 ICT/SMC 体系的了解，需要你确认。
> 约定：下面都以**看涨**为例，看跌是价格取负后的镜像。`h[i]`、`l[i]`、`o[i]`、`c[i]` 是第 i 根 K 线的高、低、开、收，`ATR14` 与项目相同（Wilder）。

## 1. 要识别的对象：三根 K 线缺口

三根连续的 K 线，下标为 `t-2`、`t-1`、`t`（`t` 是**最新一根，收盘后事件才被确认**）：

```
看涨三根缺口：  l[t] > h[t-2]
区域下沿  z_lo = h[t-2]        （第一根的高点）
区域上沿  z_hi = l[t]          （第三根的低点）
缺口大小  size = z_hi − z_lo   （必须 > 0）
缺口中点  mid  = (z_hi + z_lo) / 2
```

看跌是镜像：`h[t] < l[t-2]`，`z_hi = l[t-2]`，`z_lo = h[t]`。

**与两个体系的对应：**

| 体系 | 说法 | 几何 | 对第二根（中间）K 线的要求 |
|---|---|---|---|
| ICT / SMC | Fair Value Gap (FVG) | 看涨：K1 高点 < K3 低点，区域 = 两者之间 | 实践中偏好大实体的“位移”K 线，但定义本身不强制 |
| Brooks | micro gap / micro measuring gap | 强多头趋势棒；其后一根的低点**高于或等于**其前一根的高点 | 必须是强趋势棒 |

两者的几何完全一样：**第一根的高点与第三根的低点之间的空间**。区别只在于对中间那根 K 线的限定，以及 Brooks 允许等号。

**FVG 这一行是我的了解，不是资料内容**，如果你用的 FVG 有别的变体（比如要求位移、要求实体大小），请告诉我。

## 2. 三个等级（同一个几何，中间棒要求逐级加严）

| 等级 | 名称 | 条件 | 对应 |
|---|---|---|---|
| G3 | 纯三根缺口 | 只要求 `l[t] > h[t-2]` | FVG 的几何定义 |
| G3T | 趋势棒缺口 | G3，且第 `t-1` 根是**顺向趋势棒** | Brooks 的 micro gap |
| G3S | 强趋势棒缺口 | G3T，且第 `t-1` 根的全幅 `h−l ≥ 1.0 × ATR14[t-2]` | “强”趋势棒的保守解读，也最接近 FVG 里常说的“位移” |

**顺向趋势棒**（看涨）：`c > o`，实体占全幅比例 `(c−o)/(h−l) > 0.25`，收盘位置 `(c−l)/(h−l) ≥ 0.65`。
这与项目 `kline_features` 的 `trend_bull` 数值标准相同，但**不使用项目里“内包 / 外包优先”的规则**。原因：位移K线经常同时是外包线，如果沿用项目规则，大阳线会被误判为“外包阳线”而被排除，等于把最典型的情况漏掉。

## 3. 事件的细节规则

1. **严格大于**：`l[t] > h[t-2]` 才算缺口。Brooks 写的是“高于或等于”，但等于时两个价位重合，没有空间，不算缺口。等于的情形单独计数，不进入统计。
2. **ATR 取 `t-2` 处**：`ATR14[t-2]` 是缺口形成之前最后一个已知的波动尺度，避免被位移K线本身撑大。`ATR14[t-2]` 无效则丢弃该事件。
3. **只取连续 K 线**：`t-2`、`t-1`、`t` 之间每相邻两根的时间间隔都不得超过该周期正常间隔的 1.5 倍，否则视为跨了时段休市（周末、日内休市），缺口里会混进隔夜跳空，不是这里要研究的价格行为。被排除的事件单独计数。
4. **区间覆盖标记 `covers`**（描述，不筛选）：中间那根的范围同时盖住区域的上下沿（看涨：`l[t-1] ≤ h[t-2]` 且 `h[t-1] ≥ l[t]`）。不覆盖意味着中间还存在真正的两根K线之间的空档。
5. **去重**：若同方向在 `t-1` 或 `t-2` 已经有事件，则当前事件标记为“非首个”。强势行情里会连续出现缺口，它们共用 K 线，不是独立观测；统计时只用“首个”事件。
6. **因果性**：事件在第 `t` 根收盘后才能确定，检测只使用 `t` 及之前的数据。验证方式：把序列在任意位置截断重新检测，结果必须与完整序列在该位置之前的结果一致。

## 4. 事件之后的结果定义（从 `t+1` 根起算，看涨）

| 名称 | 条件 | Brooks 对应说法 |
|---|---|---|
| 测试 test | 某根 `l[k] ≤ z_hi`（价格回到区域上沿） | “gap test” |
| 触及中点 mid | 某根 `l[k] ≤ mid` | “consequent encroachment”（ICT 用语，非 Brooks） |
| 填满 fill | 某根 `l[k] ≤ z_lo`（价格回到区域下沿，即交易到“缺口之前那根棒的高点”以下或等于） | “closed / filled the gap” |

观察窗口默认 `N = 20` 根，另做 `N = 60` 作敏感性。窗口超出序列末尾的事件丢弃。看跌是镜像（`h[k] ≥ z_lo` 为测试，`h[k] ≥ z_hi` 为填满）。

Brooks 对这些结果的说法，也是后面要检验的对象：

- “缺口常在之后很多根内被**测试但不被填满**”（三根缺口一段）。
- “缺口是磁铁”，但回补只比回到该段上涨里其他任一根高点**稍微更**可能一点（第 6 章）。
- 早期趋势里的微型缺口应当主要当作**强势信号**，不是止盈目标（第 6 章）。

## 5. 明确**不做**的东西及原因

| 概念 | 原因 |
|---|---|
| 突破缺口 / 测量缺口 / 衰竭缺口的分类 | Brooks 自己说“要等看到市场接下来怎么走才能分类”，这是事后标签。同一个缺口可能先被看作测量缺口，后来被看作衰竭缺口，无法做因果检测 |
| 开盘跳空（Gap Openings，Reversals 第 20 章） | 针对有明确开盘的期货日内交易，24 小时 CFD 没有真实开盘缺口；项目已有 `opening_gap` |
| 岛形反转 | 依赖“衰竭缺口之后出现反向突破缺口”，是两个事后标签的组合 |
| 均线缺口棒（gap bar / 20GB） | 是价格相对 EMA 的空间，不是价格之间的空间，项目已有 |
| 测量移动目标（中点 + 起点到中点的距离） | 起点（“这条腿从哪里开始”）的选择有主观性，Brooks 自己写“often not a single choice”。**待你决定是否做**，见第 6 节 |

## 6. 需要你确认的点

1. **FVG 的几何**是否就是 `l[t] > h[t-2]`（第一根的高点与第三根的低点之间）？有没有你习惯的变体？
2. **主定义用哪一级**？我倾向于主用 G3T（Brooks 原义），G3 与 G3S 作敏感性。如果你更想验证 FVG 的“位移”版本，主用 G3S。
3. **是否排除跨时段的缺口**？我建议排除（规则 3）。
4. **结果定义**（测试 / 触及中点 / 填满）是否符合你对 FVG “被回补”的理解？
5. **测量移动目标要不要做？** 起点的选法有主观性，我建议这一轮先不做，等缺口本身的检验看清楚了再说。
