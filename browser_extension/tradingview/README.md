# PA Agent TradingView Edge 扩展

该 Manifest V3 扩展弹窗提供采集开关、品种/周期过滤、自动/手动历史截止时间、立即采集、后端连接状态、有效 K 线数、解析数据包数和过滤诊断。扩展在 TradingView 页面早期挂接 WebSocket `message` 事件，只解析 `timescale_update`、`du` 等图表序列更新包中的 K 线字段；不会转发原始数据包。扩展会校验 OHLCV、去重、排序并按 GUI 过滤，然后发送到 PA Agent 的本机回环服务 `127.0.0.1:18765`。图例当前悬停的 OHLC 不会被当作历史序列发送。

默认开启“自动获取截止时间”：扩展使用 TradingView 当前图表数据中最新 K 线的时间戳作为截止点，并显示在日期框中。Bar Replay 前进到下一根 K 线时，扩展立即把更新后的完整快照推送给 PA Agent；每 30 秒的采集闹钟仍用于补偿遗漏或连接恢复。若需手动回测时间，可关闭自动截止并填写本机时间。PA Agent 只使用截止点及之前的数据。

## 加载到 Edge

1. 启动 PA Agent，并在 Edge 打开 TradingView 图表。
2. 在地址栏打开 `edge://extensions`，开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中本目录。
4. 打开扩展弹窗，确认本机后端已连接，设置品种和周期过滤后打开自动采集；默认自动截止于图表最新 K 线，并在下一根 K 线出现时立即同步。也可点击“立即读取并同步”。

扩展请求 TradingView 图表页和本机桥接服务访问权限。K 线内容只发到本机 PA Agent。

扩展仅解析已分类为图表序列更新的数据包，并只把通过校验的 K 线发给本机后端。TradingView 可能调整私有消息格式；遇到未知格式时，弹窗会显示没有有效 K 线，数据包计数仍可用于诊断。扩展不会把其他行情消息或原始包体传给 PA Agent。
