# PA Agent TradingView Edge 扩展

该 Manifest V3 扩展右侧边栏提供采集开关、5 分钟回测开关、品种/周期过滤、自动/手动历史截止时间、立即采集、后端连接状态、有效 K 线数、解析数据包数和过滤诊断。扩展在 TradingView 页面早期挂接 WebSocket `message` 事件，只解析 `timescale_update`、`du` 等图表序列更新包中的 K 线字段；不会转发原始数据包。扩展会校验 OHLCV、去重、排序并按 GUI 过滤，然后发送到 PA Agent 的本机回环服务 `127.0.0.1:18765`。图例当前悬停的 OHLC 不会被当作历史序列发送。

侧栏打开时会通过本机桥接实时显示 PA Agent 的阶段一/阶段二思考文本、模型回答和最终决策。文本由 Agent 直接推送，只在 Agent 进程内存和当前侧栏页面内临时存在；扩展不会把 LLM 思考、回答或决策写入 `chrome.storage`，关闭侧栏后这些显示内容即释放。需保持 PA Agent 运行并使用 TradingView 扩展数据源。

先在 TradingView 开启 Bar Replay 并选择起始位置，再打开“5 分钟回测”。扩展先推进并同步一根作为本轮分析对象；随后等待 PA Agent 完成该 K 线分析，再依据同一条 LLM 实时事件流中的完成消息推进下一根并同步。回测开启期间，如果你直接点击 TradingView 图表上的“下一根/上一根”，扩展也会把回放位置变化后的快照同步给 Agent，并以该位置更新当前待分析 K 线；扩展正在自动推进时则由自动推进流程负责同步，避免重复发送。进入分析后的异常会保存在 Agent 的失败记录；数据准备阶段的异常写入 Agent 日志。失败棒会自动跳过并继续，连续三棒失败后自动暂停，避免持续的 API/配置错误跳过整段回放。取消分析会停留在当前棒。回测期间错误显示在状态和原始调试页，不弹阻塞式错误对话框；入场机会继续显示在决策面板和回测记录中，不弹窗打断推进。侧栏实时输出和回测推进共用一个本机 WebSocket 通道与事件序号；连接时的当前输出也随握手快照发送。该模式只接受 5 分钟图表。未找到回放工具栏、下一根按钮不可用或回放位置未变化时，侧栏显示原因。PA Agent 收到推进后的快照后自动运行两阶段分析，并将前一轮成功分析作为连续性上下文，供模型复核此前的入场/持仓决策及入场点调整。每轮完整分析仍写入 `records/pending`；入场成交、持仓变化、TP1/TP2、最终止盈/止损和每根已处理 K 线另写入 `records/backtest/{品种}_5m.json` 与 `.jsonl`，图表会按成交 K 线时间戳标出入场、分批止盈和最终离场。

持仓盈亏使用 1 个抽象单位按价格点计算，不代表真实账户金额或合约手数；设置 TP2 时，TP1 默认平掉一半，TP2 或止损处理剩余仓位。入场所在 K 线如果同时触及止损与目标，仍按止损优先；如果只触及止盈，则先记入场并将止盈判定延后到下一根 K 线，避免把入场前发生的高低点算作成交。普通持仓 K 线若同时触及止损和目标，OHLC 无法还原盘中先后顺序，按保守规则记止损优先并在记录中标记歧义。每次重新开启回测会建立新的会话；同一会话中手动把 Bar Replay 倒退时会清空当前模拟仓位并开始新时间线。关闭回测开关会停止自动推进与分析触发。

周期过滤默认为“全部周期”。可以先用 TradingView 分别打开需要的主周期和高周期图表完成预采集，再切回主交易周期；PA Agent 会按品种和周期分别保存快照，开始交易后不再要求切换高周期图表。

默认开启“自动获取截止时间”：扩展使用 TradingView 当前活动序列边缘作为截止点，并显示在日期框中。Bar Replay 中如果“下一根/上一根”只改变图表显示而没有产生新的 WebSocket K 线数据包，扩展会读取图表 OHLCV 图例并匹配已缓存 K 线，同步推进或回退截止时间；图例匹配结果在诊断中标记为 `legend`。TradingView 有时会先创建 `O=H=L=C` 的新 K 线占位棒。回测自动推进会等待有效截止棒确实前进后才通知 PA Agent；如果只有占位棒，扩展会继续等待，并在超时时同时显示图表边缘与有效截止棒时间，避免误报已同步或重复分析旧棒。同步时仍会排除横线占位棒，不把它作为末根数据交给 PA Agent。每 30 秒的采集闹钟仍用于补偿遗漏或连接恢复。若需手动回测时间，可关闭自动截止并填写本机时间。PA Agent 只使用截止点及之前的数据，并用主周期截止时间统一截断所有高周期快照。

## 加载到 Edge

1. 启动 PA Agent，并在 Edge 打开 TradingView 图表。
2. 在地址栏打开 `edge://extensions`，开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选中本目录。
4. 点击一次扩展图标打开 PA Agent 右侧边栏；边栏会在切换 TradingView 图表标签页时保持打开，不再以点击后消失的弹出窗口呈现。确认本机后端已连接，设置品种过滤。普通采集可按需打开；回测时在 PA Agent 中选择 TradingView 数据源及对应品种的 5 分钟周期，在 TradingView 开启 Bar Replay 并选择起始 K 线，再打开扩展的“5 分钟回测”。扩展先推进并同步当前分析对象，后续等 Agent 完成消息再推进。

扩展通过本机 WebSocket 订阅 Agent 的分析完成消息。若回放工具栏没有可访问名称，扩展会用浏览器级 `Shift+→` 输入推进一根 K 线；这需要扩展的 `debugger` 权限。该权限只在发送快捷键时连接目标 TradingView 标签页，随后立即断开。

扩展请求 TradingView 图表页和本机桥接服务访问权限。K 线内容只发到本机 PA Agent。

扩展仅解析已分类为图表序列更新的数据包，并只把通过校验的 K 线发给本机后端。TradingView 可能调整私有消息格式；遇到未知格式时，侧栏会显示没有有效 K 线，数据包计数仍可用于诊断。扩展不会把其他行情消息或原始包体传给 PA Agent。
